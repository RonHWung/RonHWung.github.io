# 2026-08-15：本地预览一键脚本

记录时间：2026-08-15（Asia/Shanghai）

在仓库根目录增加 `preview-local.cmd`，供 Windows 环境双击启动本地预览。

脚本行为：

- 自动切换到脚本所在的项目目录。
- 检查 `pnpm` 是否可用。
- 如果 4321 端口上的预览已经运行，直接打开浏览器，不再重复启动服务。
- 如果缺少项目依赖，自动执行安装，并将 pnpm store 保存在项目目录的 `.pnpm-store/` 中。
- 启动 Astro 开发服务器，等待服务可以访问后再打开默认浏览器。
- 关闭脚本窗口或按 `Ctrl+C` 可停止由脚本启动的服务器。

命令行用户仍然可以使用 `pnpm dev`；一键脚本只是 Windows 本地维护入口，不参与线上部署。

已在 Windows 环境通过双击脚本实测：Astro 完成初始化后，`http://127.0.0.1:4321/` 可以正常访问。
