# 2026-10-09：地图首页融入原资料终端

本轮范围收敛为原 `terminal-v1` 网站加地图首页。时间线、事件详情及其他栏目直接恢复归档提交 `2dd03eb` 的源文件；全站样式、上下导航、字体和原有动效恢复旧版。基础布局仅增加首页标记，地图样式在首页单独载入。文字、绘画、照片、内容数据和摄影署名未改动。

地图使用固定方位的正交相机，默认正俯视。左侧垂直滑条下端为 0°，上端为从正俯视偏转 60°；滚轮、捏合、加减按钮共用控制。全程尺度变化为 18%，初始构图同时考虑两个端点的占屏要求。拖动边界由当前投影的地面范围决定，窗口调整时重新计算；允许地图边缘适度裁切。

建筑本体、附属网格、文字标记和首页内容入口共用目的地。选中实体使用独立材质参数，整栋建筑高亮并产生轻微扫光，其他建筑和地形保持静止。预览在鼠标对侧展开，进入框内后位置固定；点击可固定预览，Esc 或关闭按钮收起。减少动态效果偏好保留静态高亮。

地图沿用已有精修几何，不降低细节。加载插图重新从实际俯视画面生成。软件 WebGL 仍使用完整模型、固定光照与烘焙阴影；不能加载地图时保留原生栏目链接。

预览菜单继续支持 1 新版、2 旧版、3 同时查看、Q 关闭。新版服务运行在菜单拥有的子进程中，避免 Astro 在代理环境中后台化后无法随菜单关闭。旧版读取固定提交的静态快照，无需旧版本地分支。

正式分支归并为 `main`，旧版提交保留为 `terminal-v1` 标签；移除原 `atlas-ui` 和 `terminal-v1` 分支。通过正常提交快进更新，不改写历史，不运行 GitHub Actions。

验证包含既有 39 页静态构建、媒体与链接检查，以及地图俯仰、投影方向、拖动范围、建筑实体交互、预览两侧与位置保持、触屏、键盘焦点、无 WebGL 降级和旧版页面交互。额外检查桌面、笔记本与手机窗口的 0°、30°、60° 构图及旧版栏目视觉对照。

Intel Iris Xe / D3D11 上，实体悬停时实际绘制约 60 fps；帧间像素变化限定在选中展馆区域。该测量对应本机硬件路径，不能代表所有设备。私有审阅图和详细数据保存在仓库外的工作目录。
