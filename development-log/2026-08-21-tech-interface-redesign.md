# 2026-08-21：轻科技界面改版

记录时间：2026-08-21（Asia/Shanghai）

## 改版目标

在保留茸磺原有黄、绿、青蓝配色和个人作品温度的基础上，提高页面的信息密度、识别度与互动反馈。设计研究参考了明日方舟官方网站、情报中心和官方周年活动页的界面组织方式，但没有复制其图片、图标、字体文件或专有素材。

参考页面：

- `https://ak.hypergryph.com/`
- `https://ak.hypergryph.com/news`
- `https://ak.hypergryph.com/special/3rd-anniversary/index.html`

## 视觉系统

- 将柔和手账风调整为“茸磺资料终端”：使用网格、编号、状态标记、方向线、切角面板和中英文双层标签。
- 保留浅色背景和角色配色，没有直接改成黑色游戏站；深色主要用于导航、按钮与少数信息条。
- 页面大标题改用高字重、紧凑行距的理工风显示字体栈，正文继续保持舒适字重。
- 绘画、照片与角色设定图统一使用切角边框、偏移阴影和界面编号。
- 更新 favicon，使爪印标记与新的深色终端界面一致。

## 使用体验

- 顶部主导航改为 `position: sticky`，桌面与手机向下滚动时都保持可见。
- 手机导航支持横向滚动，并在进入页面时自动将当前栏目移入视野。
- 经历详情页会把“沿途记录”标记为当前栏目。
- 首页主标题拆成三个语义完整的不可拆短句，避免“来，”或单个末字独占下一行。
- 全站标题使用更严格的中文断行规则与平衡换行。
- 首页增加可链接的分区锚点，方便定位作品、技能、近期记录和角色预览。

## 互动效果

- 鼠标位置会轻微改变背景光晕、方向线与首页主图视差。
- 桌面鼠标使用准星式跟随标记；悬停链接时中心状态发生变化。
- 绘画、经历、技能和时间线卡片具有指针追踪高光、轻微透视、切角阴影和图片缩放反馈。
- 首页主图悬停时出现扫描光带。
- 页面滚动时顶部显示细进度条，内容区进入视野时产生短距离位移动画。
- `prefers-reduced-motion: reduce` 下会停用扫描、脉冲、视差和入场动画。

## 响应式检查

- 桌面宽度检查：首页、画室、做毛、茸磺档案、沿途记录、时间线及经历详情。
- 真实 390px 设备指标模拟：首页标题、正文和按钮均在视口内；固定导航有效，作品卡片单列显示。
- 时间线在窄屏继续保持横向交互，首个月份节点保留安全边距。

## 构建兼容性

- Astro 从 `7.2.1` 更新到 `7.2.4`。
- Windows + pnpm 下，Astro 内容同步使用的 Vite `astro` 环境无法直接执行 CommonJS `picomatch`；项目在 Vite 的 `astro` 与 `ssr` 环境中显式预打包该依赖。
- pnpm 使用 hoisted node linker，使框架内部依赖可以被 Vite 稳定解析；该设置记录在 `.npmrc`。
- `astro check` 与静态构建均通过，结果为 39 个页面、0 错误、0 警告、0 提示。

## 发布状态

本次改版仅保存在本地工作区，不推送、不部署。Pages 工作流继续只允许手动触发，等待视觉与内容细节全部确认后再发布。
