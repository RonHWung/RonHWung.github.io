## 交接入口

1. 阅读最新一篇日志，了解当前状态和待办事项。
2. 阅读根目录的 [README.md](../README.md) 运行本地环境。
3. 阅读 [CONTENT_GUIDE.md](../CONTENT_GUIDE.md) 新增或编辑内容。
4. 修改后运行 `pnpm validate`。
5. 提交前再次检查公开边界；正式上线前才手动运行 Pages 部署工作流。
