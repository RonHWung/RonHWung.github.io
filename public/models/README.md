# Atlas runtime assets

`ronghuang-atlas.glb` is generated by `art/build_atlas.py` with Blender 5.2.
It contains the original miniature architecture and landscape for RonHWung's
homepage. Geometry is compressed with the glTF Draco extension. Keep the
reproducible script and contract when modifying this asset.

`atlas-poster.webp` is the loading and simplified-mode landscape illustration,
rendered from the same authored scene. The original character artworks and
photographs remain in `public/media/` and are not part of the generated model.

`atlas-shadow.webp` is a fixed contact-shadow intensity map for the software
WebGL rendering path, generated by `art/bake_atlas_shadow.py` and composited over
white with a restrained shadow range. Hardware WebGL keeps real-time lighting.

from Google's Draco project. Its Apache 2.0 license is preserved at
`public/licenses/draco-Apache-2.0.txt`. Three.js's MIT notice is also
